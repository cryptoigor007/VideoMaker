# CP20 — упаковка и проверка восстановления

**Релизный артефакт:** `VideoMaker_FULL_R57_CP20_PATH_CACHE_SAFETY.zip`

Финальная сборка создаётся только из исходного дерева CP20. В ZIP включается `.env.example`, но не локальный `.env`, pyc, `__pycache__`, `.pytest_cache`, `.venv` или `.git`. `checkpoints/CP20_SOURCE_MANIFEST.json` перечисляет каждый включённый файл кроме самого manifest и содержит точные размеры/SHA-256.

Перед выдачей архив проверяется через `ZipFile.testzip`, извлекается в отдельную папку, после чего сверяются все файлы манифеста, отсутствие повторяющихся имён и отсутствие `.env`. Затем на распакованной копии повторно запускаются `compileall` и `pytest`.

Проверки исходного дерева CP20: **161 passed, 23 subtests passed**; API security **18/18**; GUI settings **70/70**; GUI/API panel **33/33**; синтетические speech/BGM FFmpeg smoke **PASS**. Тестовая панель использует временный фиктивный API-токен; его и loopback/runtime IP замаскированы в сохранённых логах.

Реальная длительная транскрипция через MLX на пользовательском Mac и полный рендер реального исходного материала не выполнялись в этой среде.
