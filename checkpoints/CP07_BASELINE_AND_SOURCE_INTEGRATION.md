# CP07 — базовая сборка полного проекта

Дата: 2026-10-12

## Назначение
Фиксирует восстановленную полную кодовую базу до целевых исправлений. Этот архив можно использовать для продолжения разработки независимо от текущей сессии.

## Что включено
- Полное дерево исходного `VideoMaker_FULL_r57-api.1`.
- Все дополнительные новые модули, тесты и более поздние файлы из рабочего дерева R57 fast-shorts.
- Восстановлен `video_maker/engines/speech_rate.py`, который импортировался `TranscribeStage`, но отсутствовал в полном исходном архиве.
- Включён `tests/test_speech_rate.py`, ранее лежавший только в audit overlay.
- `BASELINE_MANIFEST.json` — перечень файлов с размерами и SHA-256 на момент базовой сборки.

## Проверки
- `python -m compileall -q video_maker tests` — PASS.
- `pytest -q tests --disable-warnings --maxfail=1` — 83 passed, 2 subtests passed.
- ZIP-целостность и архив полного дерева — проверяются при создании CP07.

## Ограничения
Это исходный код и тесты. Проверка на данной Linux-среде не эквивалентна запуску GUI на macOS и не подтверждает субъективное качество обработки реального голоса/фоновой музыки.
