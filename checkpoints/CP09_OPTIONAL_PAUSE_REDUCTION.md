# CP09 — необязательное сокращение длинных пауз

Дата: 2026-10-12

## Реализовано в аудиодвижке
- `prepare_narration(..., remove_long_pauses=False)` получил выключенную по умолчанию опцию сокращения пауз.
- Анализ опирается на полные таймкоды отдельных слов. Если часть таймкодов отсутствует либо их покрытие не совпадает с текстом, паузы не режутся вслепую.
- Порог обнаружения длинной паузы по умолчанию — 0,55 секунды.
- Внутри фразы оставляется около 0,18 секунды; после знаков пунктуации сохраняется более длинный интервал: около 0,28 секунды для запятой/двоеточия/точки с запятой и 0,38 секунды для конца предложения.
- FFmpeg `aselect` удаляет только избыточную часть паузы; после этого заново строится непрерывная временная шкала аудио.
- Все таймкоды слов, сегментов и отдельной пунктуации пересчитываются нелинейно с учётом конкретных удалённых интервалов и последующей коррекции темпа.
- `speech_metrics` получает счётчики удалённых пауз, число интервалов, исходный и скорректированный темп.

## Важное решение
Это не агрессивная вырезка любого молчания. Короткие паузы не трогаются, а паузы после знаков препинания сокращаются меньше — чтобы сохранить дикторскую интонацию. Без галочки поведение не меняется.
